# MODULIV — Whole-Home Flat-Pack Living System
> **“Your Entire Home, Delivered in Flat Boxes.”**  
> 一间房 · 6个箱子 · 60分钟 · 0颗螺丝搞定全屋

---

## 1. 项目简介 (Project Overview)

**MODULIV** 是一家定位于全球出海市场的**全屋平装与轻居快装 DTC 品牌（Whole-Home Flat-Pack Living System）**。
我们彻底重构了传统大件家具跨境电商的重资产模式，通过**“工坊现制/现压直发（Fresh-Pressed Made-to-Order）+ 全球 DDP 专线双清包税到门（No Overseas Warehouse）”**，将客厅、卧室、餐厅、书房的整套家具拆解为符合标准国际快递规范的小包裹（单箱重量 < 22kg、厚度 < 12cm、免工具自锁装配），让全球都市年轻租客、首套房业主和民宿房东能够像拼乐高一样轻松装好一个高品质的家。

## 2. 核心差异化支柱 (The 4 Core Pillars)

| 支柱 | 核心主张 | 解决的传统痛点 |
| :--- | :--- | :--- |
| **1. 现压新鲜工艺 (Fresh-Pressed Craft)** | 下单后工坊新鲜裁切、即时抽真空压缩封箱，保证 24 小时 100% 蓬松回弹。 | 击碎海外仓挤压 6-12 个月导致海绵疲劳塌陷、面料死褶的顽疾。 |
| **2. 0 螺丝 5 分钟快装 (100% Tool-Free Snap)** | 统一采用重型机械自锁卡扣与 CNC 穿插榫卯，单人徒手咔哒拼装。 | 告别宜家几十页繁琐说明书与几十颗螺丝拧到手抽筋的噩梦。 |
| **3. 15+ 种高定面料色盘 (Bespoke On-Demand)** | 法国羊羔绒、复古灯芯绒、防抓科技布、墨绿雪尼尔等多色可选。 | 突破海外仓只敢备灰白 2 种无聊颜色的库存局限。 |
| **4. 6 箱装满整套公寓 (Zero-Drama DDP)** | 整套一室一厅拆为 6 个小纸箱，FedEx/UPS 标准快递送达，进任何微型电梯。 | 避开卡车大件派送（Freight）需要预约、进不去电梯、收上楼费（$150+）的风险。 |

## 3. 全屋 5 大平装产品系统 (The 5 Living Systems)

1. **坐感系统 (Seating System)**：ModuSofa 模块化组合沙发、CloudChair 泡芙单椅、SwiftBed 3秒折叠沙发床；
2. **桌几系统 (Surface System)**：FlatCoffee 榫卯插接咖啡几、SnapSide 磁吸边几、LiftTable 升降储物茶几；
3. **睡眠系统 (Bedroom System)**：SnapBed 免工具自锁排骨架床、FloatNight 悬浮床头柜、RollMattress 卷包床垫；
4. **收纳系统 (Storage System)**：ModuMedia 模块电视柜、GridShelf 积木置物书架、EntryRack 玄关鞋衣架；
5. **办公与周边 (WFH & Lifestyle)**：QuickDesk 快装书桌、DineBench 极简餐桌椅、PetPod 猫窝一体茶几。
