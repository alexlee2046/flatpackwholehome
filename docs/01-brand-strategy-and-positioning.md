# 第一部分：从单一软体升级为“全屋轻居快装生态”

## 1.1 为什么必须做“全屋平装生态（Whole-Home Flat-Pack）”？

单一卖沙发的 DTC 品牌获客成本（CAC）高，且复购周期长。将**压缩软体**与**平板拼装木作/钢木家具**结合，将带来三大质的飞跃：

```mermaid
graph TD
    A["从【单品买卖】升级为【全屋解决方案】"] --> B["1. 客单价 (AOV) 成倍飙升<br/>从 $500 单张沙发 ➔ $1,500~$2,500 全屋入住套装 (Move-In Bundle)"]
    A --> C["2. 全屋设计语言统一 (Aesthetic Harmony)<br/>解决年轻人跑5家店家具颜色材质不搭的巨大痛点"]
    A --> D["3. DDP 专线物流协同效应<br/>所有产品均遵循平板/压缩包裹规范, 6个箱子装下一整套公寓"]
    A --> E["4. 通用 0 工具快装体验<br/>全系统一榫卯/金属自锁, 全屋 1 小时徒手拼完, 彻底告别螺丝刀"]
```
